# Data

Large/raw data is not committed (`.gitignore`). This file documents sources and preparation so that the experiments can be reproduced.

## Synthetic images (sy1, sy2, sy3)
Generated by `src/data/synthetic.py` (256×256, piecewise-constant regions following the paper's Fig. 9). Not identical to the paper's images. Gray levels and K per image: see `docs/06_KARARLAR.md` (D-008).

## BSDS500
